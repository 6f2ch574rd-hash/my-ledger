# 📒 我的記帳本

一款簡單、快速、可離線使用的 PWA 記帳 App。免註冊、無伺服器，**每支手機的資料各自獨立、互看不見**，適合自己用，也可以把網址分享給親友，大家各自記自己的帳。

## 功能
- 一鍵記支出／收入，Emoji 分類快捷輸入
- 多本帳、多帳戶（現金／銀行／信用卡，可自訂初始餘額）
- 每月預算進度條（80% 提醒、超支變紅）
- 圓餅圖、分類排行、近 6 個月支出趨勢
- 明細按月切換、關鍵字搜尋、點擊編輯／刪除
- CSV 匯出（Excel 可開）／匯入、JSON 完整備份與還原
- 選購 4 位數密碼鎖
- 完整離線快取（Service Worker），加入 iPhone 主畫面後像原生 App

## 安裝到 iPhone 主畫面
1. 用 **Safari** 打開 Pages 網址
2. 點底部「分享」按鈕 →「加入主畫面」→「加入」
3. 主畫面出現 📒 即可使用

## 資料保存說明
資料只存在裝置本機（localStorage），不會上傳。更換手機或重置裝置前，請先於「設定 → 匯出完整備份（JSON）」備份。

## 檔案結構
- `index.html` — App 本體（單一檔案即可執行）
- `manifest.webmanifest` — PWA 設定
- `sw.js` — 離線快取
- `icons/` — 主畫面圖示（PNG 由 `icon.svg` 透過 GitHub Actions 自動產生）
